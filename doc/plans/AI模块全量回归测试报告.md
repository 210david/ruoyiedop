## 四、关于 embedding 的说明

**当前不配置也完全可用**：RAG 知识库已启用关键词检索模式，实测问答命中正常。

**配置后的收益**：语义级检索（同义词/模糊描述也能命中），文档量大（几十份以上）后差异明显。

**何时建议配置**：知识库正式投用、文档增多后，或出现"文档里有但问答没命中"时。配置方法：AI配置新增 `ai.embedding_url / ai.embedding_key / ai.embedding_model` 三项（通义 text-embedding-v3 / 智谱 embedding-3 / OpenAI 均为 OpenAI 兼容格式），配置后自动切换向量检索，无需重启、无需重新解析已有文档（新上传文档自动向量化；如需旧文档升级向量可删除重传）。


## 五、embedding 配置入口补齐（2026-09-15 追加）

用户反馈：AI配置页面缺少 embedding 三项配置入口。

**已补齐**：
- 后端 AiCenterController：getConfig/updateConfig 增加 embeddingUrl/embeddingKey/embeddingModel（Key 保存后不回显，仅返回 embeddingKeyConfigured 标记；留空保存沿用已存值）
- 前端 AI配置页：新增「RAG向量检索（可选，知识库语义搜索）」配置区（总开关开启时显示），含 API地址/Key/模型名三项与说明文案
- 已验证：配置读写 ✓、Key 不回显 ✓、页面渲染 ✓（浏览器实测）

**使用说明**：AI中心→AI配置→「RAG向量检索」区，填入 OpenAI 兼容的 embedding 接口（推荐通义 text-embedding-v3，有免费额度）、密钥、模型名，保存后新上传文档自动向量化；未配置时知识库为关键词检索模式（功能完整可用）。

**遗留说明**：ruoyi-admin 目标 jar 文件名临时为 ruoyi-admin-v2.jar（原文件名被系统文件锁占用），打包配置 finalName 临时修改，功能无影响；重启电脑或文件锁释放后可改回 `ruoyi-admin-v2`→`${project.artifactId}` 恢复常规命名。
