## init-mysql.bat 修复 + 新服务器导库 Access denied 定性（16:25）
- 用户在新服务器跑 import-db-cfsp.bat 报 ERROR 1045 Access denied (using password: YES)；跑 init-mysql.bat 显示 data 目录已初始化直接退出
- 定性：整包拷贝把开发机的 mysql\data（空密码 root）带到了新服务器，init-mysql.bat 原"already initialized"分支直接退出不校验密码——真实缺陷
- 修复 init-mysql.bat：已初始化分支改为先验 ZBrj@2026 → 失败再试空密码 → 检测到空密码自动 ALTER 成 ZBrj@2026 并二次验证；两连不上才提示删 data 重初始化
- 5 个 import-db 脚本全部核对 DB_PWD=ZBrj@2026、DB_NAME 各自正确；YLSP 脚本名 import-db-YLSP.bat 规范为 import-db-ylsp.bat
- scripts/README.md 操作纪律新增第 3 条：mysql\data 机器特定，跨机拷包必须先删 data 再 init
- 服务器处理：直接跑新版 init-mysql.bat（会自动把空密码改成 ZBrj@2026），或手动 ALTER USER
  - 用户确认后已删除本地模板 D://EDOP//mysql//data（336M 空密码测试数据，重命名探测确认无进程锁定后删除）；mysql 目录现仅剩 bin/lib/logs/share/my.ini，模板不再携带脏 data；init-mysql.bat 运行时会全新初始化
