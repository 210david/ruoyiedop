# EDOP 智能助手（WorkBuddy 连接器）客户接入指引

> 本指引面向客户企业员工。完成约需 2 分钟，之后即可在 WorkBuddy 对话框里用自然语言查询您企业 EDOP 平台的实时数据（库存、订单、指标等）。
>
> **您全程只需使用自己的 EDOP 账号**：不需要把密码交给任何人、不需要管理员代配置——授权凭证由您本人在授权页登录后获得，只绑定您自己的账号与数据权限。

---

## 一、前提（管理员已完成，无需您操作）

管理员已在贵司服务器部署好 EDOP 智能助手服务，并发放：
- **服务地址**：`http://<服务器IP>:3000/mcp`
- **授权页地址**：`http://<服务器IP>:3000/grant`（部署在助手服务上，浏览器直接打开）

> 部分客户环境使用备用授权页 `http://<服务器IP>:8081/edop-grant.html`（部署在 EDOP 平台上），以管理员发放的地址为准，两者操作完全一致。

## 二、接入步骤（每人一次，约 2 分钟）

### 第 1 步：自助授权，获取您的专属令牌

1. 浏览器打开**授权页地址**（建议收藏）
2. 用**您自己的 EDOP 账号密码**登录（就是您平时登录 EDOP 平台的账号）
3. 页面显示一串 **grant_token**（专属令牌）——**只显示这一次，立即复制保存**（页面上有"复制令牌"按钮，并附可直接粘贴的配置片段）
4. 该令牌有效期 90 天，期间每次查询自动续期；代表"您本人"的数据权限

> ⚠️ 令牌等同于您的查询身份，**不要转发给同事**——他们应自己登录授权页获取自己的令牌（数据范围按各自部门权限隔离）。

### 第 2 步：配置 WorkBuddy 连接器

1. 打开 WorkBuddy，进入「**连接器**」管理（加号菜单或专家·技能·连接器页）
2. 右上角「**自定义连接器**」→「**配置 MCP**」
3. 粘贴以下内容（把尖括号内容换成您的值）：

```json
{
  "mcpServers": {
    "edop-assistant": {
      "type": "streamablehttp",
      "url": "http://<服务器IP>:3000/mcp",
      "headers": { "Authorization": "Bearer <您的grant_token>" }
    }
  }
}
```

4. 保存 → 在连接器列表找到 **edop-assistant** → 点「**信任**」→「**启用**」
5. 开启新对话，直接提问即可

## 三、怎么用（自然语言，无需指令）

| 您问 | 得到 |
|------|------|
| "平台今天整体经营情况怎么样？" | 营销/仓库/采购/生产等模块经营总览 |
| "查一下智能手环 Pro 的库存" | 各仓库各批次库存分布与锁定情况 |
| "这个月销售订单合计多少？" | 销售订单明细与金额汇总 |
| "采购订单里哪些还没到货？" | 在途采购订单列表 |
| "到货及时率是多少？口径是什么？" | BI 指标值与口径说明 |

## 四、常见问题

| 现象 | 处理 |
|------|------|
| 提示"无法访问/Connection closed" | ① 确认连接器已启用（绿点）；② 联系管理员确认服务器服务在运行 |
| 提示"登录失败/接口错误" | EDOP 平台服务可能未启动，联系管理员 |
| 提示 401 / 鉴权失败 | ① 令牌是否粘贴完整（Bearer 后面一整串）；② 若 90 天未使用已过期，重新登录授权页获取新令牌并更新连接器配置；③ 若账号被停用/离职，联系管理员 |
| 数据范围和同事不一样 | **正常且是设计如此**——数据权限跟随您本人的 EDOP 账号部门权限 |
| 我改了密码/换了部门 | 改密码不影响令牌；部门调整后数据范围自动跟随，无需重新授权 |
| 想撤销授权 | 自己在 EDOP「个人中心」撤销，或联系管理员吊销；撤销后立即失效 |
| 离职/账号停用 | 令牌立即自动失效，无需额外操作 |

## 五、数据安全说明

- 助手**只读查询**：不能创建、修改、删除任何业务单据
- 每次查询在服务器留有审计记录（时间/用户/工具/结果）——**每一次查询都能追溯到具体的人**
- 您能看到的数据范围严格等于您本人 EDOP 账号的数据权限
- **平台管理员与 AI 助手在任何环节都不需要、也不应该索要您的账号密码**——凡是索要密码的，均为违规操作

## 附：部署形态速查（管理员参考）

| 形态 | 客户条件 | 授权方式 | 说明 |
|------|---------|---------|------|
| **A. 内网 HTTP + 手工令牌**（本指引默认） | 无域名/证书，纯内网 | 员工打开 `http://IP:3000/grant` 自助登录拿令牌，粘贴进连接器 | 零证书成本，每人 2 分钟；安全靠令牌 + 内网隔离 + 审计兜底 |
| B. HTTPS + 自动授权 | 有域名+证书 或 导入自签证书 | 连接器只填 url，点「连接」自动弹授权页（OAuth 2.1） | 体验最好；自签证书需每台电脑导入受信任根 |
| C. 企业控制台统一分发 | 有托管服务/多客户运营 | 管理员控制台创建，成员点「连接」即用 | 产品化形态，随 Phase 2 企业版推进 |
